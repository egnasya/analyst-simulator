# Dashboards

Папка содержит скриншоты аналитических дашбордов, построенных в Apache Superset в рамках курса «Симулятор аналитика».

Дашборды охватывают основные направления продуктовой аналитики: пользовательскую активность, пересечение аудиторий, удержание, рекламное привлечение и отток.

## 01. Feed — Main Metrics

Основные метрики новостной ленты.

**Источник данных:** `simulator_20261020.feed_actions`.

Основные показатели:

- DAU, WAU, MAU.
- Просмотры и лайки.
- CTR.
- Динамика пользовательской активности.
- Сегментация аудитории по основным характеристикам.



## 02. Feed — Operational Dashboard

Операционный мониторинг активности пользователей новостной ленты.

**Источник данных:** `simulator_20261020.feed_actions`.

Возможности:

- Анализ текущей пользовательской активности.
- Сравнение показателей за разные периоды.
- Сегментация по полу, возрасту, стране, операционной системе и другим параметрам.



## 03. Feed & Messenger — Audience Overlap

Анализ пересечения аудиторий новостной ленты и мессенджера.

**Источники данных:**

- `simulator_20261020.feed_actions`;
- `simulator_20261020.message_actions`.

Основные показатели:

- Пользователи обоих сервисов относительно предыдущего дня.
- Активные пользователи только одного из сервисов.
- Доля пересечения аудитории относительно прошлого месяца.
- Количество пользователей, активных одновременно в ленте и мессенджере.

**SQL:** `01_feed&message.sql`, `02_user_daily_service_activity.sql`.



## 04. Feed — Retention & Audience Dynamics

Анализ удержания пользователей и динамики недельной аудитории.

**Источник данных:** `simulator_20261020.feed_actions`.

Основные показатели:

- Когортный Retention новостной ленты.
- Динамика активной аудитории по неделям.
- Новые пользователи.
- Сохранившиеся пользователи.
- Ушедшие пользователи.

**SQL:** `03_retention_feed.sql`, `04_weekly_user_retention_dynamics.sql`.



## 05. User Acquisition & Churn — Part 1

Анализ эффективности рекламного привлечения и поведения новых пользователей.

**Источник данных:** `simulator_20261020.feed_actions`.

Основные показатели:

- Размер рекламной и органической когорт.
- Дневной Retention.
- Количество действий пользователей.
- Среднее количество действий на пользователя.
- Среднее количество активных дней.
- Сравнение вовлечённости рекламной и органической аудитории.

**SQL:** `05_cohort_activity.sql`.



## 06. User Acquisition & Churn — Part 2

Исследование изменения пользовательской активности и сегментация аудитории при снижении DAU.

**Источник данных:** `simulator_20261020.feed_actions`.

Основные направления:

- Сегментация пользователей по активности 23 и 24 октября.
- Выделение пользователей, активных в оба дня.
- Выявление пользователей, которые вернулись позднее.
- Определение пользователей, не вернувшихся в ленту.
- Анализ характеристик пользователей в разных сегментах.

**SQL:** `06_feed_churn_cohort.sql`.
