# SQL Queries

Папка содержит SQL-запросы для анализа пользовательского поведения в социальной сети и подготовки данных для аналитических дашбордов.

Запросы написаны для ClickHouse и используют данные учебной базы `simulator_20261020`.

## Содержание

| Файл | Описание |
|---|---|
| `01_feed&message.sql` | Объединение действий пользователей в ленте и мессенджере в единую структуру данных |
| `02_user_daily_service_activity.sql` | Определение ежедневной активности пользователей в каждом из двух сервисов |
| `03_retention_feed.sql` | Подготовка данных для когортного анализа Retention новостной ленты |
| `04_weekly_user_retention_dynamics.sql` | Сегментация недельной аудитории на новых, сохранившихся и ушедших пользователей |
| `05_cohort_activity.sql` | Анализ активности, удержания и вовлечённости рекламной и органической когорт |
| `06_feed_churn_cohort.sql` | Сегментация пользователей по активности до и после снижения DAU |

## Основные направления анализа

**1. Активность пользователей**
- Агрегация действий по пользователям и датам.
- Анализ использования новостной ленты и мессенджера.
- Определение пересечения аудиторий двух сервисов.

**2. Удержание аудитории**
- Формирование когорт по дате первой активности.
- Расчёт дневного Retention.
- Сравнение активности пользователей по неделям.
- Сегментация аудитории по динамике активности.

**3. Привлечение и отток**
- Сравнение рекламной и органической когорт.
- Анализ количества действий и активных дней.
- Исследование поведения пользователей при снижении DAU.
- Сегментация пользователей по дальнейшей активности.

## Связь с дашбордами

SQL-запросы используются для подготовки датасетов, на основе которых построены визуализации в Superset.

Соответствие запросов и дашбордов:

| Дашборд | Используемые запросы |
|---|---|
| Feed — Main Metrics | Исходная таблица `feed_actions` |
| Feed — Operational Dashboard | Исходная таблица `feed_actions` |
| Feed & Messenger — Audience Overlap | `01_feed&message.sql`, `02_user_daily_service_activity.sql` |
| Feed — Retention & Audience Dynamics | `03_retention_feed.sql`, `04_weekly_user_retention_dynamics.sql` |
| User Acquisition & Churn — Part 1 | `05_cohort_activity.sql` |
| User Acquisition & Churn — Part 2 | `06_feed_churn_cohort.sql` |
