# Data Description

В проекте используются данные учебной базы данных `simulator_20261020`.

База содержит информацию о действиях пользователей в двух основных сервисах социальной сети: новостной ленте и мессенджере.

## Source Tables

### 1. feed_actions

Таблица содержит информацию о действиях пользователей в новостной ленте.

| Поле | Тип данных | Описание |
|---|---|---|
| `user_id` | UInt32 | Идентификатор пользователя |
| `post_id` | UInt32 | Идентификатор публикации |
| `action` | String | Тип действия пользователя |
| `time` | DateTime | Дата и время действия |
| `gender` | Int8 | Пол пользователя |
| `age` | Int16 | Возраст пользователя |
| `country` | String | Страна пользователя |
| `city` | String | Город пользователя |
| `os` | String | Операционная система устройства |
| `source` | String | Источник привлечения пользователя |
| `exp_group` | Int8 | Идентификатор экспериментальной группы |

### 2. message_actions

Таблица содержит информацию о действиях пользователей в мессенджере.

| Поле | Тип данных | Описание |
|---|---|---|
| `user_id` | UInt32 | Идентификатор отправителя сообщения |
| `receiver_id` | UInt32 | Идентификатор получателя сообщения |
| `time` | DateTime | Дата и время действия |
| `source` | String | Источник привлечения пользователя |
| `exp_group` | Int8 | Идентификатор экспериментальной группы |
| `gender` | Int8 | Пол пользователя |
| `age` | Int16 | Возраст пользователя |
| `country` | String | Страна пользователя |
| `city` | String | Город пользователя |
| `os` | String | Операционная система устройства |

## Data Usage

Исходные таблицы используются для решения следующих аналитических задач:

| Таблица | Направления анализа |
|---|---|
| `feed_actions` | Основные продуктовые метрики, Retention, динамика аудитории, рекламное привлечение и отток |
| `message_actions` | Анализ активности в мессенджере и пересечения аудиторий сервисов |

Для совместного анализа ленты и мессенджера данные агрегируются по пользователям и датам, после чего объединяются в единую структуру.

## Data Storage

Исходные данные доступны в учебной базе ClickHouse и не дублируются в репозитории.

Папка содержит документацию по структуре и назначению используемых таблиц.
